# Исходный пример курса

Файлы в этой папке скопированы из учебного репозитория DAN.IT и сохранены как
референс. Рабочая адаптация находится в [`../terraform`](../terraform).

Не запускайте `terraform apply` из этой папки: здесь исходные общие S3 backend,
параметры сети и версии компонентов курса. Порядок запуска проекта описан в
[`../README.md`](../README.md).
